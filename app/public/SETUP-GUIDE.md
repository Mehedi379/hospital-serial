# হাসপাতালের TV ও মোবাইল সেটআপ গাইড (ধাপে ধাপে)

এই গাইড দিয়ে হাসপাতালের যে কেউ — IT লোক ছাড়াই — প্রতিটা রুমের TV, অ্যাসিস্ট্যান্টের মোবাইল ও রিসেপশন সেটআপ করতে পারবেন।

---

## এক নজরে: কোন ডিভাইসে কী খুলবেন

| ডিভাইস | ব্রাউজারে যা লিখবেন | কাজ |
|---|---|---|
| **রুমের TV** (প্রতি চেম্বারে একটা) | `http://192.168.1.104:5000/tv/রুমনম্বর`<br>যেমন রুম-০৩ → `http://192.168.1.104:5000/tv/03` | শুধু ওই ডাক্তারের রোগীর ডাক + ভয়েস |
| **হলের বড় TV** | `http://192.168.1.104:5000/tv.html` | সব ডাক্তারের ডাক একসাথে |
| **অ্যাসিস্ট্যান্টের মোবাইল** (প্রতি ডাক্তারের জন্য একটা) | `http://192.168.1.104:5000/assist/রুমনম্বর`<br>যেমন → `http://192.168.1.104:5000/assist/03` | ওই ডাক্তারের রোগী CALL / NEXT / MISSED |
| **রিসেপশন PC** | `http://192.168.1.104:5000/reception.html` | নতুন রোগী ভর্তি + সিরিয়াল |
| **অ্যাডমিন (ডাক্তার সেটআপ)** | `http://192.168.1.104:5000/admin.html` | ডাক্তার যোগ/বদল, রুম নম্বর |

> ⚠️ `192.168.1.104` হলো এই PC-র ঠিকানা। বদলে গেলে নিচের **"PC-র ঠিকানা বদলালে"** অংশ দেখুন।

## ধাপ ১: সার্ভার PC চালু রাখুন (সবার আগে)

এই PC-ই সব TV ও মোবাইলের "মস্তিষ্ক"। এটা বন্ধ থাকলে কিছুই কাজ করবে না।

1. `app` ফোল্ডারে `npm run dev` চালু থাকতে হবে (চালু থাকলে ব্ল্যাক উইন্ডোতে লেখা থাকে "Hospital Serial Calling System running")
2. PC-র **Sleep বন্ধ** করুন: Settings → System → Power → Sleep = **Never**
3. **একবারই:** প্রজেক্ট ফোল্ডারের `firewall-allow.bat` ফাইলে ডাবল ক্লিক → Admin অনুমতি চাইলে **Yes** → "Port 5000 is now OPEN" দেখলেই কাজ শেষ

---

## ধাপ ২: ডাক্তার সেটআপ করুন (শুধু একবার, অ্যাডমিন থেকে)

1. এই PC-র ব্রাউজারে খুলুন: `http://localhost:5000/admin.html`
2. ফর্মে দিন: ডাক্তারের নাম (ইংরেজি + বাংলা), ডিগ্রি, স্পেশালিটি, **Room/Chamber নম্বর** (যেমন `03`), **Floor** (যেমন `1`)
3. **ADD DOCTOR** চাপুন
4. ২০ জন ডাক্তার হলে ২০ বার করুন। ভুল হলে তালিকায় **Edit** চেপে ঠিক করুন

> রুম নম্বরই হলো TV-র শর্টকাট — তাই এটা ঠিকমতো দিন।

---

## ধাপ ৩: প্রতিটা রুমের TV সেটআপ (প্রতি TV-তে ২ মিনিট)

প্রতিটা চেম্বারের TV-র জন্য একই কাজ, শুধু **রুম নম্বর বদলে** দিবেন:

1. **TV আর সার্ভার PC — দুটোই একই WiFi-তে** কানেক্ট করুন (TV-র Settings → Network)
2. TV-তে **Chrome ব্রাউজার** খুলুন (Android TV-তে Play Store থেকে Chrome ইনস্টল থাকে)
3. ঠিকানায় লিখুন (রুম নম্বর বদলে):
   ```
   http://192.168.1.104:5000/tv/03
   ```
   → এইটেই রুম-০৩ এর ডাক্তারের TV। স্ক্রিনে ওই ডাক্তারের নাম + Chamber + Floor দেখাবে
4. **VOICE TEST** বাটনে একবার OK/Enter চাপুন → ভয়েস বাজলে সব ঠিক ✓
5. TV-র ভলিউম ঠিক করুন (রুমের বাইরেও শোনা যায় এমন)
6. TV-র Settings → **Energy saving / Sleep timer = OFF** করুন, নাহলে মাঝরাতে TV নিজে বন্ধ হয়ে যাবে

### ভুল করলে যা দেখবেন
- **"No doctor found for room X"** → রুম নম্বর ভুল, অথবা অ্যাডমিনে ওই রুমের ডাক্তার যোগ করা হয়নি
- **পেজই খোলে না / ERR_CONNECTION** → WiFi ভিন্ন, বা ধাপ ১-এর firewall করা হয়নি, বা PC বন্ধ

### 🚀 একবার সেট করলেই সবসময় অটো-চালু (কোনো রিমোট/ক্লিক লাগবে না)

TV-box/মিনি-PC-তে (Windows) **`TV-AUTOSTART.bat`** ফাইলটা **একবার** ডাবল-ক্লিক করুন:

1. ফাইলটা খুলে উপরের `SERVER` আর `ROOM` ঠিক আছে কিনা দেখুন (রুম বদলালে `ROOM=103` বদলাবেন)
2. ডাবল-ক্লিক করুন — "TV AUTOSTART SET HOYE GECHE" দেখলেই কাজ শেষ (একবারই লাগবে)
3. এরপর থেকে: PC/TV-box **চালু হলেই ২০ সেকেন্ড পর** Chrome নিজে নিজে ফুল-স্ক্রিনে ওই রুমের TV পেজ খুলবে — **কোনো ক্লিক ছাড়াই ভয়েস সরাসরি বাজবে** (autoplay unlocked মোডে চলে)
4. বাতিল করতে: `TV-AUTOSTART.bat REMOVE`

> স্মার্ট TV-র নিজের ব্রাউজারে (Android TV) চালালে: পেজ খোলার পর প্রথম কলেই সাউন্ড সাধারণত চালু হয়ে যায়; লাল "সাউন্ড বন্ধ" ব্যাজ দেখলে রিমোটে একবার OK চাপলেই আনলক হয়ে যাবে — পরে আর লাগবে না।

## ধাপ ৪: হলের বড় TV (সব ডাক্তার একসাথে)

হলের TV-তে শুধু খুলুন:
```
http://192.168.1.104:5000/tv.html
```
কোনো রুম নম্বর লাগবে না — সব ডাক্তারের ডাক এখানে দেখাবে ও বাজবে।

---

## ধাপ ৫: অ্যাসিস্ট্যান্টদের মোবাইল

প্রতি ডাক্তারের অ্যাসিস্ট্যান্টের ফোনে:

1. ফোন একই WiFi-তে কানেক্ট করুন
2. Chrome-এ লিখুন:
   ```
   http://192.168.1.104:5000/assist/03
   ```
   → রুম-০৩ এর ডাক্তারের নিজের প্যানেল: শুধু তার রোগীর তালিকা, CALL, NEXT, MISSED
3. চাইলে Chrome menu → **Add to Home screen** — তাহলে অ্যাপের মতো আইকন হয়ে যাবে

> 💡 **সবচেয়ে সহজ উপায় (সরাসরি ইনস্টল):** Admin প্যানেলে (`/admin.html`) ওই ডাক্তারের সারির **HOME** বাটনটা (অথবা Launcher-এ **HOME** বাটন) ডাক্তারের মোবাইলে খুলে চাপুন —
> 1. প্রথমবার একটা **লাল warning** আসবে (হাসপাতালের নিজের সার্ভারের সার্টিফিকেট, ইন্টারনেট নয়) → **Advanced → Proceed anyway** চাপুন
> 2. **"এখন ইনস্টল করুন"** বাটনে চাপলেই ব্রাউজারের **নিজের ইনস্টল ডায়ালগ** খুলবে → **Install**
> 3. হাসপাতালের লোগো আইকনসহ অ্যাপটা সরাসরি হোম স্ক্রিনে বসে যাবে, ট্যাপ করলেই ওই ডাক্তারের প্যানেল খুলবে
>
> এই সরাসরি ইনস্টল কাজ করে **HTTPS পোর্ট (5001)**-এ — সার্ভার এটা নিজে থেকেই চালু করে, আর `firewall-allow.bat` দুটো পোর্টই খুলে রাখে। সার্টিফিকেট একবার ফোনে ভরসা (trust) করে নিলে পরে আর কোনো warning দেখা যাবে না — ধাপ দেখাবে সেই পেজটাই (`/add-home.html`)। (iPhone-এ পেজটা Share → "Add to Home Screen" স্টেপ দেখিয়ে দেবে।)

## ধাপ ৬: রিসেপশন

রিসেপশনের PC/ট্যাবে:
```
http://192.168.1.104:5000/reception.html
```
রোগীর নাম + সিরিয়াল + ডাক্তার সিলেক্ট → ADD। ডাক্তার সিলেক্ট করলে রুম নিজে থেকেই বসে যায়।

## পরীক্ষা করুন (সব সেটআপ শেষে)

1. যেকোনো এক রুমের অ্যাসিস্ট্যান্টের মোবাইলে একটা রোগী **CALL** চাপুন
2. ✓ ওই রুমের TV-তে সিরিয়াল + নাম এসেছে ও ভয়েসে বলেছে (বাংলা + ইংরেজি, দুইবার)
3. ✓ হলের TV-তেও দেখাচ্ছে
4. ✓ **অন্য রুমের TV-তে কিছুই হয়নি** — এটাই সবচেয়ে জরুরি

---

## PC-র ঠিকানা বদলালে (WiFi রিস্টার্টের পরে হতে পারে)

1. `firewall-allow.bat` ডাবল ক্লিক করুন — স্ক্রিনে বর্তমান IP দেখাবে
2. নতুন IP দিয়ে সব ডিভাইসের পুরনো ঠিকানা বদলান… ঝামেলা এড়াতে রাউটারে এই PC-র জন্য **DHCP Reservation** (fixed IP) সেট করে রাখুন, অথবা IT-কে বলুন

## রোজকার ব্যবহার

- সকালে সার্ভার PC চালু → `npm run dev` (অথবা চালু থাকলে কিছুই করতে হবে না)
- TV-গুলো Chrome খোলা অবস্থায় থাকলে নিজে নিজেই কানেক্ট হয়ে যাবে
- পুরনো সিরিয়াল রোজ নতুন হয় — ডাটা `data.json`-এ জমা থাকে, PC রিস্টার্টেও হারায় না

## সমস্যা দেখা দিলে দ্রুত সমাধান

| সমস্যা | সমাধান |
|---|---|
| TV-তে ভয়েস বাজে না | পেজে **VOICE TEST** একবার চাপুন; TV ভলিউম দেখুন; Android TV-তে Google TTS-এ বাংলা ভয়েস ইনস্টল করুন |
| TV "Waiting for next call" ছাড়া কিছু দেখায় না | সার্ভার PC চালু ও `npm run dev` চালু আছে কিনা দেখুন |
| অন্য রুমের ডাক আমার TV-তে শোনা যাচ্ছে | TV-র ঠিকানায় রুম নম্বর ভুল (`/tv/03` টাইপ করা হয়েছে কিনা দেখুন) |
| মোবাইলে পেজ খোলে না | ফোন ও PC একই WiFi-তে আছে কিনা; firewall-allow.bat চালানো হয়েছে কিনা |

কোনো সমস্যায় আটকে গেলে এই গাইডের ধাপগুলো উপর থেকে মিলিয়ে নিন — ৯০% সমস্যা WiFi ভিন্ন হওয়া বা PC বন্ধ থাকার কারণে হয়।
